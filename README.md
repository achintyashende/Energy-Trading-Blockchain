# Energy Trading Blockchain

A decentralized platform for peer-to-peer energy trading using blockchain technology.
The global energy demand is expected to rise by 40% by 2030, driven by population growth, increased automation, and the adoption of electric vehicles. Current energy systems, reliant on fossil fuels, are inflexible and environmentally harmful.
Blockchain technology offers a decentralized approach to energy management, allowing consumers to become prosumers—both generating and consuming energy. This shift facilitates peer-to-peer energy trading and enhances transparency and security in transactions.
Our proposed system leverages blockchain to streamline energy trading, ensuring fairness, reliability, and efficiency. By integrating smart contracts with smart meters, we enable real-time data tracking and automated billing, paving the way for a more sustainable and resilient energy grid.

## Overview

This project enables secure, transparent, and efficient energy trading between producers and consumers using smart contracts on a blockchain network.

## Features

- Peer-to-peer energy trading
- Smart contract automation
- Transparent transaction records
- User authentication and wallet integration
- Real-time energy usage and pricing

## Architecture

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js/Express.js
- **Blockchain:** Ethereum/Solidity smart contracts
- **Database:** MongoDB 

## Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/Energy-Trading-Blockchain.git
    cd Energy-Trading-Blockchain
    ```

2. **Install dependencies:**
    ```bash
    npm install
    ```

3. **Configure environment variables:**  
    Create a `.env` file and add your configuration.

4. **Run the application:**
    ```bash
    npm start
    ```

## Usage

- Register as an energy producer or consumer.
- Connect your crypto wallet.(MetaMask)
- List energy for sale or purchase energy.
- View transaction history on the blockchain.
